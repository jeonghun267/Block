# 개발 참고 저장소 적용 원칙

Notion에 정리한 네 가지 저장소는 코드를 무조건 복사하는 의존성이 아니라 아래 역할로 사용합니다.

| 참고 프로젝트 | BlockTrade 적용 방식 |
| --- | --- |
| awesome-design-md | `DESIGN.md` 기반 시각 기준과 금지 패턴 관리 |
| agent-skills | 반복 가능한 구현·검사·인계 절차 설계 |
| Strix | 승인된 Staging 보안 검증과 출시 차단 기준 |
| OfficeCLI | 향후 NAV·리스크·감사 보고서의 기관 문서 내보내기 |

외부 저장소의 코드·프롬프트·워크플로는 라이선스, 유지보수 상태, 공급망 위험과 최소권한을 검토한 뒤 고정 버전으로 도입합니다. 운영 비밀정보나 고객 데이터는 외부 도구에 전달하지 않습니다.
